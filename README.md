# 중간고사 통합 문제집

딥러닝 · 리눅스 시스템 · 빅데이터이해 · 자바프로그래밍 중간고사 대비 문제를 한 페이지에 모은 웹 문제집입니다.
`index.html` 파일 하나로 동작하며, 설치나 빌드가 필요 없습니다.

## 구성

| 과목 | 내용 |
| --- | --- |
| 딥러닝 1–7주차 | OX · 단답형 · 객관식 · 서술형 · 계산 92문항 + 단권화 노트 |
| 리눅스 시스템 1–3장 | OX · 단답형 183문항 (단답형 자동 채점) |
| 빅데이터이해 1–7주차 | OX · 단답형 · 서술형 110문항, 기출 표시, 60점 모의고사 |
| 자바프로그래밍 | 코드 빈칸 45문제 (장문 줄 빈칸 14문제 · 빈칸 69개 포함) |

자바 장문 문제는 정답 코드를 실제로 컴파일·실행해 실행 결과를 확인했고, 오답 보기는 모두 컴파일 오류·실행 오류·다른 출력이 나오는 것을 확인했습니다.

## 사용법

- 브라우저로 `index.html`을 열면 바로 풀 수 있습니다 (PC · 모바일 모두 지원).
- 풀이 기록은 브라우저의 localStorage에 저장됩니다. 기기·브라우저마다 따로 저장됩니다.
- 주소 끝에 `#dl`, `#lx`, `#bd`, `#jv`, `#dlnote`, `#bdmock`을 붙이면 해당 과목·화면으로 바로 열립니다.

## GitHub Pages로 공개하기

1. 이 폴더의 파일을 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)`로 지정합니다.
3. 잠시 후 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다.

## 외부 리소스

- 글꼴: Google Fonts (Black Han Sans, IBM Plex Sans KR, JetBrains Mono)
- 수식: MathJax 3.2.2 (cdnjs) — 딥러닝 노트의 수식 표시에 사용

인터넷이 끊긴 상태에서도 문제는 풀 수 있고, 글꼴과 수식 표시만 기본 형태로 바뀝니다.
